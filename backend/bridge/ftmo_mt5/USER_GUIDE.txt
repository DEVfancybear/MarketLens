TradingTerminal MT5 Connector for Windows
=========================================

No source code, Python, or environment configuration is required.

1. Extract this ZIP file to a normal folder.
2. Install and open the FTMO version of MetaTrader 5. Official Windows download:
   https://download.terminal.free/cdn/web/ftmo.global.markets/mt5/ftmo5setup.exe
3. Sign in to the FTMO account with its master password and keep MT5 open.
4. Run TradingTerminalMT5Connector.exe and keep its window open.
5. Open https://tradingterminal.io.vn in Chrome or Edge.
6. In Connections & notifications, enter the same MT5 login, exact broker
   server, and master password, then choose Connect & Verify MT5.
7. When the browser asks, allow Local Network Access so the website can reach
   the Connector. The Connector itself listens only on this PC's loopback.

The Connector does not read credentials from source files or environment
variables. It accepts one-use pairing tickets from TradingTerminal and refuses
orders if the open MT5 account differs from the verified account.

Risk baseline
-------------

The Connector applies a conservative unified guard: 3% daily loss and 10%
maximum loss. Baselines are isolated per login/server and stored under the
current Windows user's local TradingTerminal application-data folder. When MT5
history contains the original funding transaction, the earliest dated positive
balance transaction is used as initial capital. If that history is unavailable,
the first observed balance is persisted as a conservative estimate and is never
automatically lowered after a loss.

The daily reference resets at midnight Europe/Prague and never below initial
capital. The maximum-loss reference trails the highest observed balance. Open
position risk at stop loss and a daily safety buffer reduce remaining allowance.
This local guard is intentionally stricter than some FTMO account variants and
cannot reconstruct broker history that MT5 does not provide. Always treat the
FTMO dashboard as authoritative and obey the stricter remaining limit.

Troubleshooting
---------------

- Connector not reachable: keep this window open, then allow Local Network
  Access for tradingterminal.io.vn in the browser site permissions.
- Account mismatch: open the same login and broker server that you verified.
- Trading not allowed: use the master password, not an investor password.
- Windows warning: verify that the ZIP came from https://tradingterminal.io.vn.
  The current build is not code-signed; choose More info, then Run anyway.

To stop the Connector, close its window.
